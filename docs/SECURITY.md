# 安全说明

## 设计原则

1. **最小权限**：不申请相机、麦克风、定位；Android 存储权限按需请求。
2. **显式确认**：破坏性操作必须二次确认；启动盘写入需输入 `ERASE <磁盘号>`。
3. **可恢复**：扫描命中文件移动到隔离区，而不是直接删除。
4. **可解释**：每个“一键”操作都展示影响范围与失败原因。
5. **不静默安装**：不会在后台安装第三方应用或模型。

## 威胁模型

| 风险 | 缓解 |
| --- | --- |
| 恶意 APK 侧载 | 显示包名/版本/大小；不替用户做安全判断；建议模拟器 |
| Wine / Winlator 容器逃逸 | 由上游项目负责；墨绿OS 仅跳转 |
| 恶意 ISO 写入 | 只允许可移动磁盘、管理员、确认短语；拒绝系统盘 |
| 文件服务器暴露隐私 | 默认只读、无认证提示、可仅监听本机 |
| UPnP 被滥用 | 仅映射用户指定端口；停止服务器时尝试删除映射 |
| 第三方镜像投毒 | 仅公开链接；提示评估镜像；支持直连 |
| 配置文件损坏 | 原子写入 + `.bak` 备份 + 启动恢复 |
| 完整性清单被替换 | 清单不替代签名；发布提供 SHA256SUMS |

## 权限说明

### Windows

- 普通权限即可日常使用。
- 管理员权限用于：WSL2 安装、启动盘写入、部分 winget 安装。
- 不会自动提权；通过 UAC 请求。

### Android

- `INTERNET`：下载 Alpine、GitHub 加速。
- 存储：扫描与文件服务器。
- 通知：长任务提醒（可选）。
- root：chroot 安装与终端；非 root 使用 Termux。
- `MANAGE_EXTERNAL_STORAGE` 仅用于本地文件扫描/共享；可拒绝并在应用专属目录使用。

### Linux

- 普通用户可运行；chroot、系统包安装、启动盘写入需要 sudo/root。
- 不自动执行 `sudo`；给出命令让用户确认。

## 敏感数据

- 配置、日志、扫描结果保存在本机数据目录。
- 不上传遥测。
- 文件服务器没有认证，禁止在公网暴露敏感目录。
- 扫描报告可能包含文件路径，分享前请检查。

## 供应链

- Electron、xterm.js、Alpine rootfs 等第三方组件遵循各自许可证。
- 发布包应附带 `SHA256SUMS.txt`。
- 当前构建未使用商业代码签名证书；Windows SmartScreen 可能提示“未知发布者”。
- GitHub Actions 构建应固定依赖版本并限制令牌权限。

## 漏洞报告

请通过项目仓库的 Security Advisory 或私下联系维护者，不要在公开 issue 中贴出可利用细节、密钥或个人数据。
